# Сервис назначения ревьюеров на Pull Request (C# / ASP.NET Core)

Решение тестового задания Авито (осень 2025) для стажёра бэкенд-разработчика, выполненное в рамках КТ2.

- **Ссылка на исходное задание:** https://github.com/avito-tech/tech-internship/tree/main/Tech%20Internships/Backend/Backend-trainee-assignment-autumn-2025
- **Стек:** C#, .NET 8, ASP.NET Core Web API, Swagger, xUnit.

## Что сделано и что не сделано

**Сделано (основной сценарий целиком):**
- Создание команды и получение её участников (`POST /team/add`, `GET /team/get`).
- Смена статуса активности пользователя (`POST /users/setIsActive`).
- Создание PR с автоматическим выбором до 2 случайных активных ревьюеров из команды автора (`POST /pullRequest/create`).
- Переназначение ревьювера на другого активного участника команды (`POST /pullRequest/reassign`).
- Перевод PR в статус `MERGED` и запрет на дальнейшую смену ревьюеров (`POST /pullRequest/merge`).
- Просмотр списка PR, назначенных конкретному пользователю (`GET /users/getReview`).
- Проверка входных данных и хранение данных в памяти (`Dictionary`).

**Не сделано и почему:**
- Нагрузочное тестирование — не влияет на работу основного сценария.

## Как запустить

Нужен установленный **.NET 8 SDK**.

Запуск сервера:
```bash
dotnet run --project PrReviewerService/PrReviewerService.csproj
```
После запуска можно открыть Swagger в браузере по адресу `http://localhost:5000/swagger` (или на порту, который напишет консоль) и протестировать все запросы.

Запуск тестов:
```bash
dotnet test PrReviewerService.Tests/PrReviewerService.Tests.csproj
```

## Как проверял

1. Написал 4 модульных теста на xUnit (`dotnet test`): проверил выбор ревьюеров без автора и неактивных участников, случай с одним человеком в команде, ошибку `409` при попытке заменить ревьювера после `MERGED` и ошибку `400` при дубле `user_id` в команде.
2. Прогнал основной сценарий вручную через Swagger UI: создал команду, создал PR, сделал `reassign` и `merge`, проверил ответы на пустые поля и несуществующие ID.
